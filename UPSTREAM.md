# Upstream provenance

This repository is a **vendor-based fork** of [api7/aisix](https://github.com/api7/aisix)
at upstream commit **`d88a2d46530918cbea0953b6dfe04fcf5d2c9350`** (cloned 2026-11-26,
branch `main`). AISIX is licensed under the **Apache License 2.0**; its `LICENSE`
is retained unmodified.

The fork ("Route Arwaky") strips team/enterprise features and adds a self-serve
OAuth login flow for free-tier LLM providers (Cline, Kilo Code) — see
`docs/PLAN.md` once added.

Modifications relative to upstream are recorded in `git log`. To sync with
upstream, diff against the commit above.
